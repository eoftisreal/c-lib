# P1 video decoding status

**P1 is not complete. The library still cannot decode an AV1 bitstream to complete
intra/inter pictures.** The missing P0 compressed-block/coefficient pipeline also
prevents end-to-end verification of fully filtered video. This change does not
advertise successful decoding where required processing is unsupported.

## No approximate success paths

The former generic smoothing deblocker, box-average SGRPROJ and small-LFSR grain
noise were not normative AV1 implementations. Required calls to those legacy
entry points now return `Unsupported` without modifying output, rather than
silently producing wrong pixels. Identity/no-filter cases remain valid where
explicitly implemented. The legacy CDEF entry point also rejects nontrivial
filtering that lacks the required frame/block context.

Use `cdef::CdefKernel` and `restoration::{RestorationSource,WienerCoefficients,
SgrprojParameters}` for the verified scalar kernels with explicit metadata and
source buffers. These kernels do not substitute invented block maps or decoded
restoration coefficients. `RestorationSource` borrows immutable pre- and
post-CDEF planes and performs the normative outside-stripe row selection,
including repeating the second preserved boundary row for the third tap row.

`DecoderState::commit_intra_picture` finalizes only the last fully parsed intra
header, only once. Actual reference refresh occurs after successful processing.
The current finalizer accepts the subset with deblocking/CDEF/restoration
explicitly off, and runs real super-resolution if required. Required remaining
filters are errors. Grain-bearing display output is an error until synthesis is
implemented; raw ungrained pixels are never reported as completed grain output.

`DecodedPictureBuffer` manages pixel ownership for this subset. It does not
pretend to save the missing inter motion fields or full CDF state. Its
show-existing behavior has the correct pixel/showability/refresh rules, while
full codec-state loading remains dependent on those future components.

## Verification

The new deterministic `tests/oracles/p1_vectors.c` fixture is generated by
unmodified libaom commit `394f9f7df624e4268fd8c894ead9f059d279e480`:

- 1,632 super-resolution rows: 8/10/12-bit, denominators 9..16, odd/small widths,
  constant, alternating, impulse and deterministic random samples.
- 3,072 CDEF blocks, plus 3,072 direction/variance comparisons: all directions,
  primary/secondary strengths, high-bit-depth fractional primary strengths,
  damping and absent picture-edge neighbors.
- 288 Wiener outputs with extreme/identity/mixed coefficient sets at all depths.
- 576 SGRPROJ outputs covering all 16 parameter sets, projection extremes,
  single-/dual-pass cases and all depths.

Restoration cases include distinct pre/post-CDEF planes, picture edges, and
stripe boundaries. Film-grain metadata is compared field-for-field and by exact
header bit count against FFmpeg `trace_headers` on an independently libaom-encoded
fixture. Additional tests cover failure atomicity, duplicate commits, incomplete
flush, reset, reference aliasing, frame IDs, hidden/show-existing pictures,
invalid parameters, every AR lag and truncated grain syntax.

These are component/subset tests, **not** proof of complete video decoding or
fully filtered-frame conformance. The old Phase 1 reference fixtures remain part
of the workspace tests. The pinned specification check now verifies 7,272 table
entries, including the 512 super-resolution coefficients.

## API changes

Legacy deblocking, CDEF, Wiener, SGRPROJ and grain functions now return
`CodecResult` where previously they returned a vector or silently returned `()`.
Handle failures explicitly and migrate real filtering to the new metadata-aware
kernels. `FrameHeader` includes optional parsed film-grain metadata.
`ExtendedFrameType::UnknownReference` indicates a show-existing prefix whose
actual frame type requires its reference slot; this is not an extra AV1 frame type.
